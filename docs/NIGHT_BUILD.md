# 밤샘 빌드 — aep-review를 세계 최고의 영어 팟캐스트·쉐도잉 앱으로

> 이 문서는 **자율 루프(`/loop`, 60초 간격)의 단일 진실원**이다. 매 반복마다
> ① 이 로드맵에서 다음 항목을 고르고 ② 구현·검증하고 ③ `python -m scripts.release "<msg>"`
> 로 버전 bump + push 하고 ④ 아래 "반복 로그"에 한 줄 남긴다. 컨텍스트가 압축돼도
> 이 파일만 읽으면 이어서 작업할 수 있다.

## 비전
Apple Podcasts를 **넘어서는** 영어 학습 앱. 핵심 차별점:
1. **쉐도잉 모드** — transcript가 단순 자막이 아니라, 문장 반복·속도·즉각 해설로
   "따라 말하기"에 최적화. Apple Podcasts 자막 화면보다 명백히 뛰어나야 한다.
2. **즉시 해설 패널** — 재생 중 현재 문장에 intermediate+ 난이도 표현/단어가 있으면
   같은 화면 하단에 한국어 해설이 실시간으로 뜬다(멈추지 않고 이해).
3. **단어카드(SRS)** — 에피소드의 어려운 단어·표현을 자동 카드화해 복습.
4. **영어 스터디모드** — chcn-review의 중국어 스터디모드에 대응. 미국 실생활 표현/단어 학습.
5. **원클릭 동기화** — 최신 에피소드까지 버튼 한 번으로.

## 최우선 (사용자 강조)
**전체 UI 완성도 + transcript 쉐도잉 모드**가 "항상 들어가고 싶은" 수준이어야 한다.
나머지 기능보다 이 두 가지의 디테일·감성·반응성을 먼저 끌어올린다.

## 아키텍처 (고정)
- 서버리스: PWA(vanilla JS) → Supabase(Postgres/Storage/Auth) + 원본 CDN 오디오. Vercel 정적.
- 무거운 생성(STT·claude·edge-tts)은 인제스트(로컬/Actions)에서만. 결과만 Supabase로.
- 데이터 모양 계약: `episodes_list` 뷰, `getEpisode`(+vocab 임베드 +transcript Storage), SRS 쿼리.
- 난이도 해설 데이터 저장처(결정): Storage `annotations/{episode_id}.json`
  = `{ "segments": { "<segIdx>": [ {term, note_ko, kind} ] } }`. 없으면 UI는 조용히 숨김.

## 루프 프로토콜
- 간격 60초(자기 페이스). 변경이 있으면 **반드시** `scripts/release.py` 로 버전 bump+push.
- 한 반복 = 작고 안전하며 **배포 가능한** 증분. 폰에서 회귀 없이 점점 좋아져야 한다.
- 새 JS 모듈 추가 시 `ui/index.html` importmap **그리고** `ui/service-worker.js` SHELL 둘 다 등록.
- 검증: 바꾼 JS는 `node --check`, 바꾼 PY는 `python -m py_compile`.
