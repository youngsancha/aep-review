# aep-review — 큰 업그레이드 제안 (사용자 승인 대기)

자율 오버나잇 모드에서 **안정성 우선** 원칙상, 아래 "큰" 업그레이드들은 직접 적용하지 않고
여기 정리해 둡니다. 아침에 원하는 항목을 골라주시면 구현/검증/배포합니다.
(이미 적용된 안전 개선: 에러 안전망 v73 · 라이브러리 진도막대 v74 · 완료표시 v75 · reduced-motion v76)

---

## A. 사전 번역(서버에서 ko 저장) — "번역 오류 0·오프라인"
- **무엇**: 인제스트(또는 별도 패스)에서 각 문장을 미리 번역해 transcript JSON 에 `ko` 로 저장.
  앱은 저장된 ko 를 바로 사용 → 런타임 MyMemory 호출/쿼터/네트워크 의존 완전 제거.
- **이점**: 번역이 즉시·항상·오프라인. 현재 클라이언트 캐시+이메일키로 대부분 커버되지만, 이게 끝판왕.
- **비용/리스크**: 문장 분할(resegment) 파이썬 포팅 필요(클라이언트와 키 일치), 번역 쿼터(MyMemory 5만/일,
  ~25 에피소드/일) 또는 Claude CLI 번역(무쿼터·고품질) 선택. 클라이언트는 ko 없으면 기존 폴백 → 점진 적용 안전.
- **추천도**: ★★★ (안정성/정확성 핵심 가치와 가장 부합)

## B. A-B 반복 / 문장 N회 반복 쉐도잉
- **무엇**: 한 문장(또는 A-B 구간)을 정해진 횟수만큼 반복 후 자동으로 다음 문장 이동.
- **이점**: 검증된 쉐도잉 훈련법. 현재 "반복"은 단문 무한반복뿐.
- **리스크**: 최근 튜닝한 쉐도잉 토글 UX 를 건드림 → 사용자 확인 필요(그래서 보류).
- **추천도**: ★★☆

## C. 스터디 데일리 스트릭 / 오늘의 목표  ✅ 일부 적용됨
- **무엇**: 매일 학습 일수 스트릭 + "오늘 N개 학습" 목표. localStorage 기반(추가형).
- **상태**: **스트릭은 적용됨**(`markStudyDay`/`getStreak`, Study 헤더 🔥칩). "오늘 N개 목표"는 미적용.
- **추천도**: ★★☆ (남은 '오늘의 목표'만 선택 적용 가능)

## D. 단어 길게 누르기 → 즉석 사전/번역 팝업
- **무엇**: transcript 단어 long-press 시 그 단어 뜻/번역 팝오버.
- **리스크**: 번역 쿼터 추가 부하 + 새 인터랙션. A(사전번역) 선행 시 안전.
- **추천도**: ★☆☆ (A 이후)

## E. 오프라인 미디어 캐싱
- **무엇**: 오디오/transcript 를 SW 로 캐시해 오프라인 재생.
- **리스크**: cross-origin CDN 캐싱은 재생 깨질 위험 큼 → 신중. (이전부터 보류 항목)
- **추천도**: ☆☆☆ (별도 신중 검토)

## F. 한→영 '말로 생산' 드릴 (Production speaking) — 회화 훈련의 끝판왕  ⬅️ 신규 제안
- **무엇**: 기존 스피킹(영어 문장 보고 따라말하기 = *모방*)과 달리, **한국어 뜻만** 보여주고 사용자가
  영어 문장을 직접 **말로 생산**하게 한다. 말한 뒤 → 정답 영어 공개 + 원어민 음성 재생 +
  v93 A/B 비교(원문↔내 발음) + 인식 점수/diff. (SR 미지원 시 녹음 폴백.)
- **이점**: comprehension·imitation 을 넘어 **production(구사)** 을 직접 훈련 — 네이티브처럼 *말하는*
  능력의 핵심. 사용자가 명시한 "네이티브 영어를 **구사**할 때 꼭 필요한 앱" 목표에 가장 직접적인 한 수.
  기존 6개 모드는 전부 이해/받아쓰기/모방이라 이 'production' 만 비어 있음.
- **비용/리스크**: `translateEnKo` 가 `episode.js`(싱크 핵심 파일) 안에 **비공개**로 있어 공유 모듈로
  추출 필요 + 스피킹 헬퍼(`wireRecognition`/`scoreText`/`diffHtml`)를 모듈 스코프로 승격해야 함.
  새 모드 자체는 추가형이지만 **보호 파일(episode.js) 리팩터를 동반**하므로, 자율 오버나잇 안정성
  원칙상 직접 적용하지 않고 제안만 둠. 한국어는 런타임 `translateEnKo`(MyMemory) 또는 제안 A(사전 ko)와 결합.
- **추천도**: ★★★ (회화 목표에 직결 — 단, episode.js 리팩터 동반이라 깨어있을 때 검증 권장.
  제안 A(사전 ko 저장)를 먼저 하면 번역 의존도 사라져 더 견고)
